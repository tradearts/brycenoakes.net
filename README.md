# brycenoakes.net

Personal website for Bryce Noakes.

## Current build

Version four is a concise job-positioned portfolio with a white, all-sans
visual system, restrained orange accents, three image-led project pages,
completed community-exhibition evidence and a neutral public CV. Case studies
surface the brief, responsibilities, constraints and outcome so the work can be
scanned as project-delivery evidence as well as visual work. Its layout is
informed by the clarity and spacing of the supplied Jordan Hughes reference
while retaining an original Trade Arts-adjacent identity.

## Local preview

From this folder:

```sh
python3 -m http.server 8088
```

Then open:

`http://127.0.0.1:8088`

## Structure

- `index.html` - page content and semantic structure
- `work/` - project case studies
- `cv.html` - source for the public CV
- `bryce-noakes-cv.pdf` - downloadable public CV
- `styles.css` - responsive visual system
- `script.js` - menu, contact link and progressive reveal behaviour
- `robots.txt` and `sitemap.xml` - search-engine discovery
- `images/portfolio/` - optimised local portfolio imagery
- `images/v2/` - curated project and studio imagery
- `IMAGE-SOURCES.md` - source and attribution record
